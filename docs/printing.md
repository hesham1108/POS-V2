# الطباعة — إعداد الطابعة الحرارية 80مم

> Phase 8. ينطبق على جهاز الكاشير (Windows) اللي عليه StoresPOS.

## إزاي الطباعة شغالة

- بعد الدفع (F9) السيرفر بيطبع **صامت** على الطابعة المختارة في **الإعدادات → الطباعة** (`DefaultPrinterName`) عبر Windows Print Spooler — من غير dialog المتصفح.
- لو الطباعة الصامتة فشلت، الـ POS بيرجع لـ iframe + `window.print()` كـ fallback.
- إعادة الطباعة من الـ POS / قائمة المبيعات بتحاول silent الأول برضه.
- المعاينة في الإعدادات لسه HTML (80مم / A4) للتعديل البصري.
- تقرير الوردية لسه browser print حاليًا.

## إعداد جهاز الكاشير (مرة واحدة)

1. ثبّت درايفر الطابعة الحرارية.
2. من **الإعدادات → الطباعة**: اختار الطابعة → **حفظ** → **تجربة طباعة صامتة**.
3. في خصائص الطابعة: الورق `80mm x Receipt` (أو 72mm printable)، الهوامش 0، وفعّل القصّ التلقائي لو موجود.
4. شغّل StoresPOS عادي في Chrome/Edge (مش محتاج `--kiosk-printing` للـ POS بعد silent print).
5. Fallback اختياري لو حابب browser print صامت:

```text
chrome.exe --kiosk-printing --app=http://127.0.0.1:5188
```

## الإعدادات (Phase 15–16)

من **الإعدادات → الطباعة** (أو `App_Data/store-settings.json`):

| المفتاح | المعنى |
| --- | --- |
| اسم/عنوان/هاتف/ضريبي/شعار | هيدر الإيصال و A4 |
| `ReceiptFooter*` | رسالة آخر الإيصال |
| `ReceiptLanguage` | `ar` أو `en` |
| `ReceiptDigits` | `western` أو `arabic` على الإيصال فقط |
| `PricesIncludeVat`, `VatPercent` | سطر الضريبة المضمنة |
| `PaperWidthMm` | 80 أو 58 |
| `DefaultReceiptFormat` | `80mm` أو `A4` — افتراضي بعد الدفع في POS |
| `DefaultPrinterName` | اسم طابعة ويندوز؛ عند الحفظ يتضبط كـ default في الـ OS |
| تoggles (شعار/باركود/عنوان/هاتف/ضريبي/A4) | إظهار أو إخفاء عناصر القالب |
| `ReceiptFontScale` | تكبير/تصغير خط الإيصال (0.9–1.2) |

### استوديو الطباعة (Phase 16)

- قائمة الطابعات المثبتة على جهاز السيرفر/الكاشير (ويندوز) + زر **تحديث**.
- اختيار الطابعة الافتراضية يحفظ في الإعدادات ويحاول ضبطها في ويندوز عشان `--kiosk-printing` يطبع عليها.
- معاينة حية لـ 80 مم و A4 (عينة) مع تعديل الخيارات قبل الحفظ.
- على أكثر من جهاز كاشير: اضبط الـ default على كل جهاز يطبع منه.

التعديل من الشاشة يتطبق فورًا (ملف الإعدادات يعيد التحميل).

## لو الطباعة مش شغالة

- **الـ dialog بيظهر كل مرة:** Chrome مش مفتوح بـ `--kiosk-printing` (لازم تقفل كل نوافذ Chrome الأول).
- **الإيصال صغير أو متقطّع:** مقاس الورق في الدرايفر مش 80mm، أو Scale مش 100%.
- **هوامش بيضا كبيرة:** Margins = None في أول طباعة يدوية.
- **معاينة من غير طباعة:** زر «معاينة» في تفاصيل الفاتورة، أو المعاينة داخل **الإعدادات → الطباعة**.
- **الطابعة الغلط:** من الإعدادات اختار الطابعة واضغط حفظ، أو اضبط Default printer في ويندوز يدويًا.
