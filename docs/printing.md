# الطباعة — إعداد الطابعة الحرارية 80مم

> Phase 8. ينطبق على جهاز الكاشير (Windows) اللي عليه StoresPOS.

## إزاي الطباعة شغالة

- بعد الدفع (F9) الـ POS بيفتح الإيصال `Receipts/Sale/{id}?autoprint=1` في **iframe مخفي** والصفحة نفسها بتنادي `window.print()`.
- نفس الفكرة لتقرير الوردية بعد الإغلاق (`Receipts/Shift/{id}`) وزر «إعادة طباعة» في فواتير البيع و«إعادة طباعة آخر فاتورة» في هيدر الـ POS.
- الصفحات دي `_PrintLayout` (بدون سايدبار)، مقاس `@page { size: 80mm auto; margin: 0 }`، أبيض وأسود، الخطوط من داخل التثبيت (offline).
- الباركود Code 128 بيترسم SVG من السيرفر (`Printing/Code128.cs`) — مش محتاج خطوط ولا إنترنت.

## إعداد جهاز الكاشير (مرة واحدة)

1. ثبّت درايفر الطابعة الحرارية واجعلها **Default printer** في Windows.
2. في خصائص الطابعة: الورق `80mm x Receipt` (أو 72mm printable)، الهوامش 0، وفعّل القصّ التلقائي لو موجود.
3. شغّل StoresPOS في Chrome أو Edge بوضع الطباعة الصامتة عشان مايظهرش dialog كل فاتورة:

```text
chrome.exe --kiosk-printing --app=http://127.0.0.1:5188
```

   (`--kiosk-printing` يطبع مباشرة على الطابعة الافتراضية. `--app` يفتح نافذة بدون شريط عنوان.)
4. اعمل اختصار على سطح المكتب بالأمر ده للكاشير.
5. أول مرة من غير `--kiosk-printing`: اطبع إيصال تجربة، وفي نافذة الطباعة اختار الطابعة، Margins = None، وألغِ Headers and footers. Chrome بيفتكر الاختيارات دي.

## الإعدادات (`appsettings.json` → `Store`) لحد شاشة الإعدادات في Phase 11

| المفتاح | المعنى |
| --- | --- |
| `NameAr` / `NameEn`, `AddressAr` / `AddressEn`, `Phone`, `TaxNumber` | هيدر الإيصال |
| `ReceiptFooterAr` / `ReceiptFooterEn` | رسالة آخر الإيصال |
| `ReceiptLanguage` | `ar` أو `en` — لغة الإيصال (لغة المتجر، مش لغة واجهة الكاشير) |
| `ReceiptDigits` | `western` (123) أو `arabic` (١٢٣) على الإيصال فقط |
| `PricesIncludeVat`, `VatPercent` | سطر «شامل ضريبة القيمة المضافة 14٪» (قرار مفتوح — الافتراضي 14٪ شامل) |
| `PaperWidthMm` | عرض الرول (80 افتراضي؛ 58 للطابعات الصغيرة) |

بعد تعديل الملف: أعد تشغيل التطبيق.

## لو الطباعة مش شغالة

- **الـ dialog بيظهر كل مرة:** Chrome مش مفتوح بـ `--kiosk-printing` (لازم تقفل كل نوافذ Chrome الأول).
- **الإيصال صغير أو متقطّع:** مقاس الورق في الدرايفر مش 80mm، أو Scale مش 100%.
- **هوامش بيضا كبيرة:** Margins = None في أول طباعة يدوية.
- **معاينة من غير طباعة:** زر «معاينة» في تفاصيل الفاتورة أو صفحة إغلاق الوردية يفتح الإيصال في تاب جديد.
