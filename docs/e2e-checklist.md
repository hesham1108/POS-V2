# اختبار وظيفي من طرف لطرف (Phase 15)

نفّذ على جهاز فيه SQL حقيقي بعد `dotnet ef database update`. سجّل الدخول من جديد بعد الترقية.

## رحلات المستخدم (plan.md)

| ID | الرحلة | نتيجة |
| --- | --- | --- |
| A | أول كاشير: دخول → فتح وردية → بيع → إغلاق → دخول | ☐ |
| B | كاشير ثانٍ: استئناف وردية مفتوحة | ☐ |
| C | وردية قديمة: تنبيه → استئناف أو إغلاق | ☐ |
| D | بيع قطاعي F9 + إيصال (80 مم أو A4 حسب الإعدادات) | ☐ |
| E | مصروف نقدي من POS / الوردية | ☐ |
| F | شراء → استلام في مخزن → تحديث أسعار | ☐ |
| G | مرتجع → رجوع للمخزن البيّاع | ☐ |
| H | إغلاق + تقرير وردية + نسخ احتياطي (لو مفعّل) | ☐ |
| I | طباعة A4 من المبيعات | ☐ |
| J | بيع/شراء بشيك | ☐ |
| K | تحصيل/سداد شيك → خزنة | ☐ |
| L | إيداع/سحب/تحويل خزائن | ☐ |
| M | تحويل بين مخزنين | ☐ |
